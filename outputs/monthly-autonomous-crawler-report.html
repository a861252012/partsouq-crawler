Code review 修正摘要

Challenge false positive
合法頁面內嵌 Turnstile 不再被當作整頁 challenge。
Main-frame raw capture
排除 iframe response，等待初始 403 轉成 final stable 200。
Secret-safe logging
URL 的 ssd／VIN 預設遮罩；MySQL password 不進 command/config。
No dead pipe
DB event writer 失敗會立刻結束 child，不等 child 因 stdout backpressure 卡死。
Hard-kill terminal state
Attempt 用完且 lease inactive 時自動落 completed_with_gaps。
Bounded challenge retry
同 profile、30 分鐘、最多 3 次；不是高頻 403 brute retry。

部署與操作

# 初始化獨立 browser worker
python3.12 -m venv .venv-browser
.venv-browser/bin/pip install --requirement browser_worker/requirements.txt

# 啟用 timer
sudo install -m 0644 deploy/systemd/partsouq-monthly-sync.service /etc/systemd/system/
sudo install -m 0644 deploy/systemd/partsouq-monthly-sync.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now partsouq-monthly-sync.timer

# 查看 DB 與 journal
partsouq-crawler monthly-status --period 2026-08 --event-limit 200
journalctl -u partsouq-monthly-sync.service --since '2026-08-01'

正式 host 必須先用相同 Chrome、Xvfb、profile、service user 與 egress IP 跑一頁 probe，驗收 final 200／parsed true。未通過就不能啟用 PartSouq current 完成聲明。
